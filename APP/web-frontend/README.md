# Web 浏览器前端（localhost）

此目录属于独立 Web 仓库，保留原页面、素材和图纸编辑逻辑，使用 Taro H5 构建，不通过跨项目导入读取小程序源码。

已实现：浏览器文件选择、必要时本地缩图、fetch/FormData 上传、原生 Canvas、鼠标点按编辑、触屏手势、浏览器存储和 PNG 下载。未保存的转换预览只在内存中，刷新丢失；已保存作品留在当前浏览器。浏览器存储不足时会显示保存失败。

导航固定在底部，使用奶油米色并预留滚动空间。编辑/看图画布按实际 CSS 宽度绘制，鼠标与触摸事件转为画布局部坐标；编辑落点使用已绘制的视口，排除坐标轴和拖动手势。预览、编辑器、看图三个下载入口统一导出横向 4:3 PNG，保留完整网格、坐标和颜色用量。用量从当前格子重算，色系从所选品牌色卡读取；看图页同步显示。

推荐从仓库根目录执行 `./start-local.ps1`，统一地址 http://localhost:5188。单独构建为 `npm ci`、`npm run build`；检查为 `npm run typecheck`、`npm run test:contract`。`npm run dev` 在 127.0.0.1:5181 启动 H5 热更新并把 /api 代理给已运行的本地后端。

当前不做用户登录。请求通过本地入口校验来源和请求头后进入独立 FastAPI 后端。阿里云密钥及服务凭据不进入浏览器包。此构建不支持直接对接普通部署入口或云端地址；公开版认证仍待确定。
